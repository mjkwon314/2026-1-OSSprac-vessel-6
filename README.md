# 팀 웹사이트에서 기여한 내용
## 김태형 : Result Page / 각종 애니메이션 효과 구현
### 담당 및 구현 기능
1. index page : 페이지 상단에 팀번호:팀명, 홈/입력/팀원 버튼 추가, 캘린더 및 일정 추가 기능 구현, 프로젝트 진행 과정 및 Docker 배포 정보 구현, 다크모드 버튼 구현, 팀 레포지토리로 연결되는 깃허브 링크 버튼 추가

2. input page : 팀원 정보 입력 안내 hero영역 추가, 기본 정보/연락정보/기술 스택 입력 단계를 보여주는 안내 카드 추가, 입력 폼을 섹션별 구조로 정리

3. result page : 초기 페이지 구현, 등록 완료 배너 구조 추가, 등록 인원, 검색, 필터 상태를 보여주는 요약 정보 추가, 입력된 팀원 리스트 검색기능 구현, 필터 영역 구조 개선, 결과카드와 하단 이동 버튼 구조 개선

4. contact page : 팀원 수, 주요 기술 스택을 보여주는 통계카드 추가, 이메일 버튼 클릭시 해당 메일로 메일 보낼 수 있도록 기능 구현, 팀장/팀원 프로필 카드 구조 개선, 이름/학과/역할/기술스택을 검색하여 팀원을 찾을 수 있도록 구현

5. 기타 : localStroage를 이용한 다크모드 유지 기능 추가, 현재 페이지 네비게이션 active 표시 기능 추가, Docker hub에 웹페이지 업로드, Flask API 라우트 추가

### 사용 기술
- HTML5
- CSS3
- JavaScript
- Flask
- Docker
- AOS Library
- Python

- 권민재 : Input Page / Client-side Logic Implementation

`input.html` 페이지의 웹 화면 골격을 직접 구축, 브라우저 단에서 동작하는 클라이언트 사이드 데이터 처리 로직 구현. 

자바스크립트를 활용해 화면의 동적 인터랙션을 제어하고, 입력된 데이터를 경량화된 CSV 파일로 가공 및 다운로드하는 기능을 성공적으로 개발하여 시스템의 독립성과 효율성을 높였다

### 담당 및 구현 기능

- 입력 페이지(input.html) 전체 구조 및 정렬 레이아웃 설계 (순수 HTML/CSS 기반)
- 사용자 정의(기타) 기술 스택 입력 필드 및 기술 선택 버튼 동적 활성화 UI 구조 배치
- 사용자 조작에 따른 팀원 동적 추가(Add) 및 삭제(Delete) 인터랙션 기능 구현
- 팀원 추가 시 연락처(Contact) 섹션에 해당 정보가 실시간으로 연동되는 화면 로직 제어
- 서버 연동 없이 브라우저 단에서 데이터를 취합하는 클라이언트 사이드 데이터 처리 로직 구현
- 순수 자바스크립트 기반의 데이터 파싱을 통한 경량화된 CSV(.csv) 파일 즉시 다운로드 기능 개발

### 사용 기술

- HTML5
- CSS3
- JavaScript
- CSV Data Parsing

- 이영민 : Main Page / UI Enhancement

메인 페이지(index.html)를 담당하여 팀 프로젝트의 전체 구조와 주요 기능들을 한 화면에서 확인할 수 있도록 구성하였다.

기존의 단순한 메인 화면을 개선하여 Hero Section, 프로젝트 소개 영역, Docker 배포 정보 영역 등을 Dashboard 스타일의 랜딩 페이지 형태로 재구성하였으며, Flask 기반 팀 프로젝트의 메인 진입 화면 역할을 수행하도록 구현하였다.

또한 사용자 경험(UI/UX)을 개선하기 위해 여러 시각 효과와 애니메이션을 추가하였다.

### 담당 및 구현 기능

- 메인 랜딩 페이지(index.html) UI 및 레이아웃 구성
- Hero Section 및 Dashboard 스타일 디자인 구현
- 팀 프로젝트 소개 및 기능 안내 섹션 구성
- GitHub / 입력 페이지 / 일정 페이지 연결 버튼 구현
- AOS(Animation On Scroll) 기반 스크롤 애니메이션 효과 적용
- Glassmorphism 스타일 및 카드형 UI 디자인 적용
- 메인 페이지 반응형 레이아웃 및 시각 효과 개선

### 캘린더 시스템 기능 개선

캘린더 기능은 팀원이 기본 구조를 구현하였으며, 추가적으로 다음 기능들을 개선 및 구현하였다.

- 일정 유형(회의 / 개발 / 발표 준비 / 배포)별 색상 구분 기능 구현
- 등록된 일정 수정(Edit) 기능 추가
- 일정 카드 스타일 및 사용자 인터페이스 개선
- team.py 수정 및 Flask API 연동 기능 보완
