메인 페이지(index.html)를 담당하여 팀 프로젝트의 전체 구조와 주요 기능들을 한 화면에서 확인할 수 있도록 구성하였다.

기존의 단순한 메인 화면을 개선하여 Hero Section, 프로젝트 소개 영역, Docker 배포 정보 영역 등을 Dashboard 스타일의 랜딩 페이지 형태로 재구성하였으며, Flask 기반 팀 프로젝트의 메인 진입 화면 역할을 수행하도록 구현하였다.

또한 사용자 경험(UI/UX)을 개선하기 위해 여러 시각 효과와 애니메이션을 추가하였다.

### 담당 및 구현 기능

- 메인 랜딩 페이지(index.html) UI 및 레이아웃 구성
- Hero Section 및 Dashboard 스타일 디자인 구현
- 팀 프로젝트 소개 및 기능 안내 섹션 구성
- GitHub / 입력 페이지 / 일정 페이지 연결 버튼 구현
- AOS(Animation On Scroll) 기반 스크롤 애니메이션 효과 적용
- Glassmorphism 스타일 및 카드형 UI 디자인 적용
- 메인 페이지 반응형 레이아웃 및 시각 효과 개선

### 캘린더 시스템 기능 개선

캘린더 기능은 팀원이 기본 구조를 구현하였으며, 추가적으로 다음 기능들을 개선 및 구현하였다.

- 일정 유형(회의 / 개발 / 발표 준비 / 배포)별 색상 구분 기능 구현
- 등록된 일정 수정(Edit) 기능 추가
- 일정 카드 스타일 및 사용자 인터페이스 개선
- team.py 수정 및 Flask API 연동 기능 보완
